# Third-party sources

- ARIS: https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep , pinned commit 2901234ad2954cd2388ced8d3aed2ed9de42803a, MIT License. The project-local installer is a one-line scoped adaptation of the upstream Windows installer. License text: third_party/ARIS-LICENSE.
- WITT: https://github.com/KeYang8/WITT , pinned commit 2460db52264ad35d0d7521c9f505fc318134c086. Author source is retained locally under baselines/upstream/WITT and imported for replication; that upstream directory is excluded from this project's code repository. Setup instructions must preserve the paper citation and acquire the source separately.
- CVPR 2026 author kit: https://github.com/cvpr-org/author-kit , release CVPR2026-v1(latex), commit 12909ae437f6dbc7435069cfdb4ca44c18e6a02f. The original template is retained under templates/upstream/cvpr2026. It is a formatting reference, not a claim that this course project has been submitted to or accepted by CVPR.
- CIFAR-10: https://www.cs.toronto.edu/~kriz/cifar.html . Dataset archives and images are excluded from the code repository. Cite Alex Krizhevsky, Learning Multiple Layers of Features from Tiny Images, 2009.

Downloaded papers and full-text extraction files are kept as local reading material. The project reports cite their original sources.

Small TeX run-file packages are staged from a CTAN mirror under third_party/texmf solely for local compilation. Individual source URLs, versions/file listings and archive checksums are recorded under downloads/tex. These packages retain their upstream licenses; no ownership of their source is claimed. The texmf directory should be reacquired from the recorded archives rather than included in this project's code release.
