\begin{abstract}
We study post-training lookup-table deployment of the signal-to-noise ratio (SNR) gates in WITT, a transformer for wireless image transmission. Fourteen small conditioning networks depend only on scalar SNR, yet account for 4,150,272 learned parameters in our configuration. We replace these networks with 13-node FP32 tables and linear interpolation while retaining the image-dependent computation and channel-use ratio. For one locally trained checkpoint on CIFAR-10 with an additive white Gaussian noise (AWGN) channel, the complete serialized deployment file decreases from 54,987,545 to 38,644,489 bytes, a 29.72\% reduction. Validation determines the table choice before a frozen evaluation on 10,000 test images, eight predeclared SNRs, and three paired noise realizations. The maximum signed decrease in peak signal-to-noise ratio (PSNR) is 0.000186 dB on these test conditions. This reproducible deployment study documents the storage--reconstruction tradeoff, a nearest-neighbor failure case, and the distinction between table knots and interpolated conditions.
\end{abstract}
